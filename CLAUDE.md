## Git Operations — HARD RULES (NO EXCEPTIONS)

Every `git commit`, `git push`, `gh pr create`, and any command that writes to the remote is BLOCKED until I explicitly say to do it in that moment. "Open a PR" is approval for that PR only — not for future commits or pushes in the same conversation. Each destructive or remote-writing git operation requires its own explicit approval. Do not infer ongoing permission from a previous approval.

- **NEVER commit without my explicit approval.** Show me the diff and wait.
- **NEVER push without my explicit approval.** Tell me what you want to push and wait.
- **NEVER create PRs without my explicit approval.**
- **NEVER force push.** Only if I explicitly tell you to, and that will be rare. Default to creating new commits instead of amending.
- **NEVER reset or drop databases without my explicit permission.**
- Always run tests and lint before proposing to push.

If in doubt, ask. The cost of asking is zero. The cost of an unauthorized push is my trust.

When committing changes, NEVER add `Co-Authored-By:` trailers. Write a semantically correct commit message only
